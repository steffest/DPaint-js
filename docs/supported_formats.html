Supported File Formats

DPaint.js reads and writes to a bunch of common graphical file formats.

PNG

Both 24-bit as 8-bit indexed PNGs are supported.
Animated PNG is not supported, so when saving to PNG, only the current frame is saved.
PNG files don't support layers, so the image is flattened before save.
Transparency is supported, but how it's stored depends on the PNG type:
  • 24-bit PNGs retain full alpha transparency.

  • 8-bit indexed PNGs only support on/off (binary) transparency, not partial alpha: fully transparent pixels are saved as transparent, everything else becomes opaque (soft/anti-aliased edges are flattened).
    When transparency is present, how it's stored depends on the palette size:
    • < 256 colors: a dedicated transparent palette entry is added, so no image colors are affected.
    • = 256 colors (full palette): there's no room for a new entry, so a palette index that no opaque pixel uses is reused for transparency. If every one of the 256 colors is used by an opaque pixel, transparency and that last color can't both be kept and the background color index is reused as a fallback.
    With the Optimize palette option (the default), the palette is rebuilt from the colors actually used in the image on save, so a true-color image keeps its colors. Choose Current to write with the existing palette instead.
